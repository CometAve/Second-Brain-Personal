# 로딩 로고 형상과 검수 경계

앱의 정적 브랜드 표시는 원본 `src/shared/components/icon/Logo.svg`를 사용한다. 회전 로고는 원본 이미지의 x/y 위치를 수동 추적한 35개 점과 깊이를 보완하기 위해 추정한 12개 점으로 만든 47점·135간선 고정 연결망이다. 원본 한 장에서 z 깊이, 뒷면, 교차선의 실제 접합 여부는 알 수 없다. 따라서 정확한 3D 복원이나 픽셀 단위 동일성을 주장하지 않는다.

이전 35점 구조는 60°·120°에서 긴 관통선과 큰 평면이 드러났다. 현재 구조는 47점·90면의 닫힌 볼록 표면이며, 추적한 원본 96간선 중 64개를 유지한다. 모든 각도에서 같은 135간선을 그린다. 0°부터 360°까지 1° 간격의 오프라인 그리기에서 간선 수와 투영 크기를 점검했다. 이 기하 검사만으로 실제 회전의 시각적 품질을 판정하지 않았다.

[원본과 0°·60°·120°·180°](loading-logo-comparison.png), [30° 간격 전체 회전 정지 자료](loading-logo-47-360.png), [실제 Canvas 회전 영상](loading-logo.webm)을 함께 남겼다. [렌더러 비교 페이지](loading-live.html)는 실제 `drawLogoFrame`으로 240/96px와 355°→35° 구간을 검수하기 위한 별도 페이지다. 앱 경로의 로딩 위치·준비 전환은 [19항목 결과](motion-result.json)로 확인했다. 실제 앱 대기 시간을 늘려 한 바퀴를 촬영하지는 않았다. 숨긴 탭, 동작 줄이기, Canvas 실패와 빠른 unmount는 [렌더러 9항목 결과](loading-logo-motion-result.json)의 합성 조건이다.

회전은 고정된 Y축으로 4.5초마다 한 바퀴 돈다. 화면 주사율마다 속도가 달라지지 않도록 경과시간으로 각도를 구한다. 47점 브라우저 표본의 300프레임에서 간격 중앙값 13.3ms/P95 15.7ms, Canvas 그리기 CPU 중앙값 0.1ms/P95 0.3ms였다. 이는 로고 그리기 범위의 관찰값이며 앱 전체 성능이나 실제 로딩 시간의 개선률이 아니다.
